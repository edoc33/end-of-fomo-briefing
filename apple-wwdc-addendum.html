WWDC 2026  |  The announcement

Apple builds page monitoring into Safari.

Notify Me lets a user name the change they are waiting for and leave Safari to watch the page.

The prompt is concrete: “when registration opens.”
Safari keeps checking after the user leaves. The alert arrives as a push.
Scope at launch: one page per request, Safari on Apple devices.

Since the keynote

Cadence is confirmed: checks run daily at most, on a set schedule. Still open: where the checks run, page limits, and change history.

The return path  |  Contested ground

The alert becomes the answer.

Safari comes back when the page changes. The return path is now platform territory.

Image: Apple / WWDC 2026
Apple gets the return path on iPhones and Macs this fall.
Google’s information agents arrive this summer, gated to AI Pro and Ultra subscribers.
The open web version has run for years: page monitoring agents that watch any page in any browser, with the exact diff as the receipt.
Why it matters

Search answers once. The web keeps changing. Whoever owns the alert owns the return visit.
